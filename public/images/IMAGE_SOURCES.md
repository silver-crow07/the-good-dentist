# Temporary image sources

All photographs in this directory (and its subfolders) are **temporary stock
photos** used only to exercise layout, responsive behaviour and the mock
appointment flow. Replace them with real clinic photography before launch.

Map (`map-placeholder.svg`) and any remaining root-level `*.svg` files are
illustrative placeholders generated by `scripts/generate-placeholders.mjs`.
